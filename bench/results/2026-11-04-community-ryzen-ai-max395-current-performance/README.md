## 测量方法

本轮完成 **41 次正式请求 + 2 次不计分预热**，串行发送到当前正式服务；所有请求 HTTP 200，`timings.cache_n = 0`。
主模型、正式配置和引擎 SHA-256 保存于 [runtime.json](runtime.json)。测试期间没有更换参数或重启引擎。

常规吞吐、完整算法与思考、生产 smoke、64K/260K 纯文字输入均找回了历史请求或匹配了提示词 SHA-256。
这些请求只替换 API 模型别名，保留原采样、思考和输出上限。对照是 **10 月的历史测量与现在的完整部署**；包含 57K 词表和服务版本等差异，不是同日重跑旧引擎，也不能归因于某一条引擎优化。

工具任务原先只保存提示词哈希与输出，无法恢复完整 messages，因此重建同类任务，并单独报告。图片采用保存的合成测试图；近满上下文加图片重新组装输入，实际 token 数在下表列出。
