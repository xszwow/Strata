# Windows gfx1151 上的 FP16 预填充实测

2026-11-13，Ryzen AI Max+ 395、Radeon 8060S、128 GB 统一内存。Huihui UD-IQ4_XS、原生 Q4 MTP、56,919 项草稿词表、单槽、INT8 KV。引擎基于本 fork 的 0.1.56。

在同一个 HIP 程序上切换 `STRATA_PF_DM16`。开启后，受支持的专家层以 FP16 写入中间结果，合并时转回 FP32。两次开启均从运行日志确认第 0 层在 8,312 token 的预填充块执行了新路径。

## 同机对照

| 工作负载 | 关闭时中位数 | 开启时中位数 | 变化 |
| --- | ---: | ---: | ---: |
| 8,313 token 预填充 | 6.421 秒 | 6.311 秒 | -1.73% |
| 32,889 token 预填充 | 25.824 秒 | 25.466 秒 | -1.39% |
| 代码输出 | 59.900 TPS | 60.200 TPS | +0.50% |
| 中文说明输出 | 38.600 TPS | 38.650 TPS | +0.13% |

按关、开、开、关顺序进行四次独立启动，每次先用 8K 请求预热，再对每个性能项目运行两次，第二次颠倒项目顺序。表中每个开关状态有四个有效样本，所有性能请求均读取了完整输入。预填充秒数来自引擎的 `prompt_ms`，输出速度来自 `predicted_per_second`。样本规模只适合判断这一台机器上的重复性。

## 正确性和部署

- 四次启动共完成 48 个计入统计的请求。其中 16 个工具请求覆盖长上下文多工具选择、Responses 函数调用、Codex 历史工具名迁移。逐项比对工具名和参数，Codex 返回的 JavaScript 检查了外层工具名、嵌套命令及语法。
- 8K 和 32K 均准确找回三个校验值。代码和中文题作为吞吐样本，内容仅做基本检查。相同工作负载的四个性能项目在本次两种开关状态下各自的可见输出摘要一致。
- 发布构建移除一次性路径日志；HIP 专用调用只在编入融合内核时启用。格式标记使用线程本地状态，宽批次路径显式标为 FP32。Windows 架构默认值单元测试通过。
- 正式引擎重启后重新执行八项核心用例，并通过 64K 三值检索和六项中文图片字段检查。实际加载的可执行文件、开关和模型状态均已核对。公网鉴权和真实 SSE 回复验收通过。本轮没有测量整套 0.1.59、DFlash2、其他硬件或全上下文上限。CUDA、SYCL、Metal 构建未在本机执行。
