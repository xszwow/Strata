# IVYUN 助手

原生 JavaScript 前端与 Express 后端，支持流式对话、Markdown、表格、Chart.js、Mermaid、数学公式、Word/Excel/PDF 文本解析、PNG/CSV/SVG/Mermaid 源码/XMind 导出及用户和邀请码管理。

通用对话和多步骤任务共用执行循环，图表按用户需求渲染。多步骤任务可调用 `task_update` 保存目标、进度、有效方法及下一步。清单按会话和当前消息分支传递，最多 32 项，支持待处理、进行中、待跟进、已完成。每次更新在 SQLite 提交后才发送事件，浏览器收到后保存到原会话；较早的对话压缩后会重新注入当前清单。简单问答可以直接回答。

已保存的待办在输入框上方显示一行会话进度，默认收起。待办进度与清单属于同一张卡片，共用外框、圆角和背景；同一个入口切换「展开 / 收起」，整张卡片向上增高，短清单随内容定高，长清单在可用空间内滚动。输入框和入口位置保持不动，展开时仍能输入、发送和停止；没有遮罩或额外的高度档位。进度更新不自动打开面板，也不移动正在阅读的位置。等待和未完成事项跨轮保留，停止后显示暂停；全部完成的清单在下一次提问时从入口隐藏，历史消息仍可展开查看。每个会话分别保存展开状态，刷新可恢复；打开面板不会重新执行任务。组件按 [TASK-UI.md](TASK-UI.md) 划分数据、状态、渲染和布局职责；界面刷新不写历史，旧数据在读取边界转换，新计划默认收起。验证：`pnpm test:tasks-ui`。

压缩历史时保留成功结果、有效工具用法与待核验操作，省略旧失败尝试的参数和报错细节。当轮失败仍返回模型用于修正。原始会话保存在浏览器 IndexedDB，压缩只改变下一次请求的上下文。发送前先保存准备状态，关页后可重建尚未提交的请求；已经提交的生成只通过原生成编号续传。服务端重启导致续传过期时，返回最近 24 小时内持久化的待办检查点供继续处理，完整已收取历史以浏览器保存记录为准。

## 运行

要求 **Node.js 24+**（使用内置 `node:sqlite`）及 pnpm 11。应用前端保持原生 JavaScript；安装脚本复制浏览器依赖，并使用 esbuild 将 Remend 和 idb 打包为两个独立小文件。请执行下面的完整安装命令，安装过程需要开发依赖中的构建工具。

```powershell
cd server
pnpm install --frozen-lockfile
Copy-Item .env.example .env
# 生成一个随机 JWT_SECRET，填写到 .env；不要提交真实配置。
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
pnpm start
```

启动前在 `server/.env` 填写：

| 配置 | 含义 |
| --- | --- |
| `JWT_SECRET` | 至少 32 字符的随机签名密钥，不能使用示例值 |
| `DEFAULT_API_URL` | 完整 `/chat/completions` 接口 URL；公网接口要求 HTTPS，本机回环接口允许 HTTP |
| `DEFAULT_MODEL` | 该接口实际支持的模型 ID |
| `DEFAULT_API_KEY` | 免费额度使用的系统密钥；留空时用户可配置个人密钥 |
| `MODEL_CONTEXT_WINDOW` | 上游未报告容量时的备用上下文大小；默认 0 显示未知 |
| `REASONING_MODE` | 默认 `auto` 识别 llama/Strata；可明确设为 `llama`、`openai` 或 `disabled` |
| `ADMIN_PASSWORD` | 至少 12 字符的独立管理密码；留空即禁用管理接口 |
| `HOST` / `PORT` | 默认 `127.0.0.1:3000`，通过反向代理发布时仍可保持回环监听 |

其他额度、长度、并发及超时配置见 `.env.example`。修改配置后重启。所有聊天、图表修复、密钥验证使用同一服务端模型及接口；前端不能覆盖模型或输出上限。

`MAX_OUTPUT_TOKENS` 默认 `-1`，沿用 llama-ui 不单独限制输出的语义。llama/Strata 接口收到 `max_tokens=-1` 后按剩余上下文计算可生成量；其他接口不发送该字段，使用提供方默认值。正整数仍可指定上限。Low/Medium/High 的推理预算为 512/2048/8192，Max 取消单独推理预算，Default 保留模型默认。模型面板同时显示真实上下文容量及输出策略。

`REQUEST_TIMEOUT_MS` 和 `BROWSER_REQUEST_TIMEOUT_MS` 是连续无上游活动的时限，模型的推理、正文、进度、心跳和浏览器轮次活动会重新计时。正常长回复不会因总时长超过两分钟而中断；上游持续无数据仍会超时，停止和断线续传规则继续生效。

访问 `/login.html` 注册/登录，`/chat.html` 对话，`/settings.html` 设置个人密钥，`/admin.html` 管理用户与邀请码。

## Chrome 浏览器接入

复用工作区现有 `browser/` 的 Strata Chrome 扩展、11 个 `browser_*` 工具和实时画面流。直接在对话中要求打开网页、读取数据或操作页面即可；模型调用工具后，画面自动出现在当前回复最新的操作步骤下方，随输入、点击、滚动持续更新。画面没有额外菜单栏、地址栏或固定高度留白，沿用 llama UI 的正文内预览方式。

在 `server/.env` 配置以下项目后重启图表助手：

| 配置 | 说明 |
| --- | --- |
| `BROWSER_BRIDGE_URL` | 同机桥接为 `http://127.0.0.1:18086`；远程可填写已经提供这些接口的 Strata HTTPS 网关 |
| `BROWSER_BRIDGE_KEY_FILE` | 桥接认证文件绝对路径，例如工作区 `private/public-access.json`；也支持纯文本密钥文件。或使用 `BROWSER_BRIDGE_KEY`，二者选择一种 |
| `BROWSER_ALLOWED_USER_IDS` | 允许使用这台 Chrome 的图表助手账号 ID，逗号分隔；留空不开放给任何账号 |
| `BROWSER_BRIDGE_START_SCRIPT` | 同机可选：工作区 `browser/server.cjs` 的绝对路径，连接被拒绝时启动现有桥接；远程部署留空 |
| `BROWSER_MAX_ACTIONS` | 每次用户请求最多工具调用数，默认 200，可配置 1–200；读取、等待、历史查询、失败尝试与结束工具均计数 |
| `BROWSER_REQUEST_TIMEOUT_MS` | 浏览器任务连续无活动超时，默认 600000ms；普通请求使用 `REQUEST_TIMEOUT_MS` |

上限统一来自 `public/js/core/browser-protocol.js`，生产启动器沿用服务端默认值。模型每轮在动态 task 中收到总额度、已用/剩余次数，剩余 10 次开始核验收尾；最终文字说明不占工具额度。前端保留最多 201 轮模型记录和 207 条步骤记录（包含最后一批被上限拒绝的调用），避免旧 100 条限制截掉长任务。连续 5 次动作失败、会话丢失、浏览器占用时仍提前停止。

断线续传：浏览器请求最多缓存 32 MiB / 400000 个事件，普通聊天保持 8 MiB / 100000 个事件；所有任务合计保留的 SSE 载荷上限为 128 MiB，另允许每个任务一条终止错误。最多 16 个任务，最长保留 24 小时；容量不足时先淘汰最早完成且无人续传的缓存，不驱逐运行中的任务。刷新只续传原任务，不重新执行工具。已保存到本机的历史不受服务端缓存淘汰影响。

长任务回归：在 `server/` 运行 `node tests/browser-budget.test.js`，使用隔离 Chrome 和模拟模型跑满 200 次，覆盖第 120 次后的刷新续传、收尾提醒、最终总结及 IndexedDB 历史恢复；不发送真实网站消息。

本机预览 `work/ivyun-composer-preview.cjs` 已配置现有桥接和本机预览账号。Chrome 需要加载并连接现有“Strata 浏览器助手”扩展；安装方法见工作区 `browser/README.md`。只读取或操作本次任务创建的标签页，沿用该 Chrome 的网站登录状态。公网部署不会将本机的 `127.0.0.1` 自动变成远程可达地址，需要使用已有认证网关；发布配置应明确指定获授权账号。

模型工具循环由 `server/browser-agent.js` 执行：拼接流式工具参数、串行执行、回传页面结果，支持视觉的模型每轮附带当前页面截图。只接受现有 11 个工具；客户端不能指定桥接地址、认证密钥或任意工具。整个用户回合只结算一次额度；多轮模型调用统计分别保留最新上下文占用和累计生成用量。

`public/js/core/browser-view.js` 按已有 llama UI 的 `browser/web/panel.js` 改编：同一任务只保留一个画面、跟随最新操作、EOF 和网络恢复自动重连、25 秒无数据看门狗、最大 10 秒退避。`server/browser-event-stream.js` 复制并适配原 `browser/event-stream.cjs` 的发送队列，慢连接只保留最新待发送帧，优先送出状态与任务结束事件，避免旧帧越积越多。

新生成的浏览器任务按模型轮次保留推理、阶段回复及操作记录，放在默认收起的「执行过程」中；可点击或用键盘展开。实时画面独立于折叠容器，最终回答单独渲染，不混入前面的阶段回复。用户展开后，后续流式更新不会重置展开状态；刷新后仍可查看已保存的过程，默认收起。只有模型实际返回推理时才显示推理文本。验证：`pnpm test:browser-process`。

账号和对话共同绑定服务端浏览器会话，其他账号/对话不能订阅画面。刷新或返回原对话会重新订阅仍在活动中的任务，不新开 Chrome 标签页。操作名称、状态、显示参数和文字结果随消息保存在当前浏览器；输入文字在显示参数中仅保留字符数，截图和桥接会话密钥不写入步骤结果。任务完成由模型调用 `browser_finish`；停止生成、请求失败或超时会主动清理所属任务，原桥接的五分钟无操作清理仍生效。普通文本回复结束本身不关闭未完成的浏览器任务。

同一会话的后续请求会携带已保存的阶段回复、操作及文字结果，不再只发送最终正文。出错、停止或未生成最终正文的轮次也保留已有操作，并标明未完成状态；没有正文或执行记录的空回复不参与上下文。历史网页结果保持为不可信资料，移除结构化的旧元素引用、标签页/页面档案编号、截图及会话密钥，不回传内部推理。每条回复的重复结果去重；整个请求的历史结果文字共享 48000 字符预算，超出时明确标注节选和原长度，操作状态、等待结果、用户消息、附件和回复正文不会因此截断。服务端原有消息数量和输入长度上限继续生效。该修复读取既有历史字段，不迁移或改写旧记录；此前未保存的事实无法补回。验证：`pnpm test:memory`，包含实际网页发送、SSE、IndexedDB 刷新、重新生成、会话隔离和最终回复失败后的请求检查，模型和浏览器操作均使用本地模拟服务。

验证命令：`pnpm test:browser-tools`。覆盖模型工具分片、多轮回传、额度、权限隔离、取消、未知工具、操作上限、连续画面、旧帧丢弃、发送拥塞、刷新恢复、最新步骤定位、断线/无数据重连与 320–1440px 响应式布局。工作区 `work/ivyun-browser-live-check.cjs` 另用真实本地模型和现有 Chrome 扩展，验证打开本机验收页、填写、点击、读取随机校验码、生成表格、结束任务及连续画面更新。

## 结构和职责

下方输入区按当前 Strata 所接的 LlamaUI **b11530** 源码适配：两层输入布局、真实模型信息、上下文占用、会话独立的推理档位，以及手机底部面板。原始源码、固定提交、模块对应关系和接口规则见 [LLAMA-UI-SOURCE.md](LLAMA-UI-SOURCE.md)。

```text
public/                         唯一可通过 HTTP 读取的目录
  *.html, images/, vendor/
  css/components/               对话组件、共享账号表单及登录/注册样式
  css/pages/                    设置页、管理后台各自的完整样式
  js/core/                      状态、API、SSE、依赖加载和 UI
  js/managers/history-manager.js 账号隔离的 IndexedDB 持久化
  js/processors/markdown-processor.js Markdown、数学、图表渲染和实例销毁
  js/handlers/                  消息、文件、图表、弹层和导出
server/
  config.js                     统一配置及启动校验
  db.js                         SQLite 事务与旧 JSON 导入
  upstream.js                   上游请求、超时、取消、SSE 与背压
  routes/, middleware/          HTTP 路由、输入校验和认证
  private/data.sqlite           运行时数据库（不在 public 内）
  tests/                        HTTP 集成与浏览器回归
  scripts/                      依赖同步、语法及静态资源引用检查
```

页面资源已从根目录迁入 `public/`。不要再把项目根目录配置为 Nginx 或其他静态服务根目录。应用只公开 `public/`；后端源码、配置、数据库、部署文档不在静态目录内。

## 数据与迁移

- 用户、密码哈希、个人 API 密钥、邀请码、额度和结算记录保存在 SQLite。启用 WAL、外键及用户名/邀请码唯一约束。数据库包含敏感信息，应限制运行账号之外的文件访问。
- 如存在旧 `server/data.json`，第一次启动会在一个事务中迁移，并记录完成标记；原 JSON 保留、不覆盖。重复启动不会再次导入。重复用户名等不一致数据会使迁移失败并回滚，应先检查旧数据；不会猜测合并账号。
- 旧用户的历史 `api_url` 不再各自生效，所有密钥必须属于当前配置的服务商。切换服务商前确认用户密钥的适用范围。
- 聊天历史通过 idb 存取浏览器 IndexedDB，主键由用户 ID 和会话 ID 组成；当前会话指针也按用户隔离。数据库名称、版本和结构保持与前一版一致，已有记录无需重建。换设备不会自动同步。
- 旧 `localStorage.chat_history` 没有账号归属，因此不会自动显示给任何登录用户。历史面板提供“导入此浏览器旧版记录”，由用户确认归属后导入，原始记录继续保留。
- 标题直接取首条用户消息，不调用模型、不扣额度。正文先保存；模型返回、停止、失败均保存到请求开始时所属会话。
- 生成中刷新或关闭页面会取消请求；再次打开时未完成记录显示“已中断”，不会无限显示加载状态。停止后的 Markdown 原文保留。
- 重新生成最后一条回复沿用原消息 ID；重新生成较早回复会创建分支，保留原会话的后续内容。

## 额度规则

1. 请求经过校验后，事务内预留一次免费额度。余额不足时使用个人密钥，未配置则返回明确错误。
2. 上游返回首段非空回复内容或首个合法浏览器工具调用时提交扣费。开始输出/执行工具后的主动停止、断线或后续失败仍消耗一次额度；同一浏览器回合的多轮模型调用不重复扣费。
3. 在任何有效内容产生之前发生错误、超时或取消，退回预留额度；结算具有幂等性。
4. 进程异常退出留下的未提交预留，在超过请求时限加 5 秒宽限后，于启动或下一次聊天请求中回收；本进程仍在执行的请求预留不会按年龄误退款。当前服务按单个应用进程运行。
5. AI 图表修复是用户显式发起的生成请求，按钮明确提示消耗一次额度或个人密钥。历史标题不产生请求。

## 渲染与性能

- Markdown 通过 Marked 解析后经 DOMPurify 白名单清理，原始 HTML 按文本显示；链接只允许 HTTP(S)、邮件和锚点。文件名、文件正文和后台用户名以文本节点插入。
- Mermaid 使用严格安全模式及 SVG 清理，KaTeX 禁用信任命令。特殊图表源码始终保存为文本。
- 第一段内容立即显示，后续输出以 60ms 批量更新富文本。Remend 只修整展示中的未完成 Markdown，模型原文和保存内容保持不变。尚未闭合的代码围栏显示源码，闭合后立即渲染图表；已完成的内容块和 Chart 实例在后续输出及回答结束时复用。
- Chart.js、Mermaid、KaTeX、代码高亮和文件解析库按需加载。切换会话、重新生成及删除消息时销毁图表实例；异步加载完成后检查渲染版本，避免创建已离开页面的图表。
- 大图弹层按需加载 Panzoom 管理拖动和双指缩放，保留滚轮、工具栏、鼠标双击、触摸双击、重置和首次自动适配。超长图先完整居中显示，细节可继续放大查看。
- Mermaid 支持直接下载 SVG 和 `.mmd` 源码，原有 PNG 和思维导图 XMind 导出继续保留。
- 文件限制 20MB，并检查提取文本长度。附件文本会发送给所配置的模型服务，原始文件在浏览器本地解析。
- CSV 保留空值和零，统一转义逗号、引号与换行。散点图按每个系列的 X/Y（气泡图另含 R）列导出。
