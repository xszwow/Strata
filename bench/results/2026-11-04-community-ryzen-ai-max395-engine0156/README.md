# Strata 本机升级实测与部署结果（2026-11-04）

已启用 Strata 0.2.10 的服务代码及 0.1.56 引擎源码，移植本机 Q4_0 MTP 支持后编译为 `strata-native-mtp.exe`。正式端口 8080，候选端口 8081 已关闭，模型监控正常。

机器为 Windows / Ryzen AI MAX+ 395（gfx1151）。主模型为原 Huihui UD-IQ4_XS，24576 个专家全部驻留 GPU；保留 HyF 56919-token 词表、MTP 窗口 8、16K 预填充分块、int8 KV、262144 上下文和原推荐采样。图片继续使用已有的高分辨率预热编码器。

最新上游核对为 [v0.2.10，2026-11-02 发布](https://github.com/Niko1221/Strata/releases/tag/v0.2.10)，对应 Control / 引擎 0.1.56。版本与原文保存在 [upstream-release.json](upstream-release.json)。

## 合入内容和保留选择

- 新版 HIP 引擎及 Strix Halo 默认优化、服务端图片取消、提示词编码缓存、工具输出解析与恢复。
- 本机原有 Q4_0 MTP 补丁移植到新引擎；补丁源码、构建记录和引擎摘要均已保存并核对。
- 公网兼容层适配新旧 Python 服务，继续提供跳过思考、准备阶段计时、图片前文本前缀复用；启动器按配置中的 `cwd` 加载对应服务。
- 保留原主模型、采样、262144 上下文、57K 草稿词表、窗口 8、16K 分块及关闭多会话 RAM 停放的设置。
- 32K 分块本轮在 32K / 64K 提示词上仅快约 0.4% / 0.8%，且增加缓冲内存需求，因此继续用 16K。
- DFlash2 更省草稿显存，英文说明较快；在本机这组中英混合任务上不如 Q4 MTP 均衡，还新增一个原 MTP 答对的算术失败，因此不设为默认。清理后保留测试数据和来源信息，试验权重不再占用磁盘。

- [正式完整质量验收](production-final-quality.json)：生成的完整代码通过 11 个输入；开启思考的算术题回答正确；Responses、Anthropic Messages、真实跳过思考均通过。
- [正式基准与功能结果](production-final.json)：工具调用与返回、图片识别、长文本校验码、普通前缀缓存均通过。复用第二次约 11.9K-token 前缀后只需重新处理 7 个提示 token。
- [图片和文本前缀联合验收](local-acceptance.json)：两次识别均正确，第二次确认实际提示词缓存复用。
- [公网验收](public-acceptance.json)：15 项通过，覆盖 TLS 请求、匿名和错误 Key 拒绝、Bearer 和 x-api-key、登录、模型别名、正式 IVYUN 生成、已完成生成的事件续传重放、取消协议及浏览器状态接口。网络中途物理断线未在本轮人为制造。
- 上游服务测试共运行 1385 项，31 项跳过；唯一初次错误来自中文 Windows 的 `tasklist` 输出被按 UTF-8 解码。对应 Windows 作业测试在使用本地编码后 3/3 通过。完整日志为 [初次结果](upstream-serve-tests2.stderr.log.txt) 和 [编码环境修正后的重跑](upstream-winjob-rerun.log.txt)，不将初次运行描述为全绿。
- 本项目现代服务回归 67/67、启动器配置 14/14、新旧兼容层分别 16/16、IVYUN 服务端 29/29 通过；相应日志同目录保存。

关闭思考的 `arithmetic-1000` 样例，原版与选定新版都答成 266333，正确值为 234168。这个模型的既有失败仍存在；开启思考的独立验收答对。DFlash2 另把 `arithmetic-15` 答错，因此没有用它替换默认草稿器。

公网验收还发现并修复了已有 Nginx 配置对不存在的 `@strata_login_required` 的引用；它把认证拒绝的 401 变成 500。已删除失效的 error_page 规则，保留认证检查，并修改 UI 部署脚本以防再次发布时带回该问题。修复日志记录保存在本机报告，服务器上保留原配置备份。

Linux 多卡切分、其他 GPU 后端、DeepSeek / 新模型与桌面 App UI 的变化不属于本机当前 Windows 单卡、原模型和 IVYUN 网页的升级范围，未把那些功能的上游成绩写成本机实测。

## 构建来源与复现

当前引擎来自上游 v0.2.10 / engine 0.1.56 加本 fork 原生 Q4/Q8 MTP 补丁。构建产物 SHA-256 为 `37dc9ac37def7a5bc04ff61b91780254da406ff54d8b8bbd271047a00f6d76d6`；源码摘要见 [构建记录](artifacts/native-build-manifest.json)。本轮只构建和实测 Windows HIP / gfx1151；其他 GPU 后端未在本机重建验证。

安装步骤及配置生成器见 [安装教程](../2026-10-12-community-ryzen-ai-max395-huihui-iq4xs/README.md)。使用 `-UseHyf57K` 可启用本次测量的词表。脚本固定 MTP 并移除 DFlash2 参数。不要直接用缺少本 fork 补丁的官方引擎加载这个 Q4 MTP runtime。

`inputs/` 保存合成长输入、静态提示词和测量条件；JSON 保存原始回复、失败样例、计时和配置。临时测试执行脚本、旧引擎和实验权重已按维护要求删除。此处本机路径和公网地址已替换为占位符，因此不是可直接启动的配置；`configuration_sha256` 等字段记录原始文件摘要，不是脱敏副本的摘要。不要把日志中的历史路径当作当前安装步骤。

公网及 IVYUN 结果来自本机额外的私有部署兼容层，属于部署验收记录；这些入口程序不在本 Strata 源码仓库中。历史构建日志中失败的尝试保留在本机报告，本目录发布成功的最终 HIP 构建日志。
